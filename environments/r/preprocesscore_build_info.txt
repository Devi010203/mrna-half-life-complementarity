The original successful scientific environment rebuilt this exact official source
with its supported --disable-threading option. Conda's package record alone does
not capture that source override. Its binary package can fail on this host with
pthread_create() return code 22 even when R_THREADS=1.

Reproduce the source override after creating the recorded conda environment.
This preserves version 1.72.0 and the normalization algorithm; it disables only
the internal threaded implementation. The dependency source/binary is not bundled
with this repository. See README.md in this directory for installation and smoke
test commands. A version-number check alone is insufficient.
