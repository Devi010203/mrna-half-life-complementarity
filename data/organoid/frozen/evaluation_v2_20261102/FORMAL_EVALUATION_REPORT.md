# GSE336417 shCtrl：新增外部人类测量验证正式报告

2026-11-02。**正式评价完成；独立统计复核 PASS。**所有分析按性能计算前冻结的 v2 执行，v1 原文件与冻结记录保留。未训练、推理、重新拟合融合或根据结果修改集合。未改动手稿、既有正式数据或 GitHub 发布包。

## 1. 主要发现

在单一 MSK107Li 患者来源结直肠癌肝转移类器官 shCtrl 背景的 **4,890 个基因**上，Bio-XGB 的排序预测优于 LM，Bio-Fusion 进一步取得小幅增益：

- 唯一主要比较，Bio-Fusion−Bio-XGB：**ΔSpearman = +0.017859，95% 配对 bootstrap CI [0.012561, 0.023250]**。
- 预先新增的次要比较，Bio-XGB−LM：**+0.141271 [0.117630, 0.164869]**。
- 五个原外层测试折中，Bio-Fusion−Bio-XGB **5/5 为正**。折诊断未参与选模或权重调整。
- 同一 4,801 基因集合上，五模型在新类器官半衰期上的 Spearman 均低于在原 Saluki 和 External-PC1 上的值，融合增益仍保留。

这补充的是**在另一实验/生物学背景下，整体相关性降低但预测互补性仍存在**的证据。增益幅度不大，不能把正向区间等同于大的应用收益，也不能把相关性下降唯一归因于类器官、肿瘤或测量平台。

## 6. 测量与统计解释边界

1. **R²_exp >0.6 仅表示满足原作者采用的对照衰减拟合标准，不等于半衰期具有很高测量精度。**本轮基于已发表处理结果，不恢复原始峰值判定或拟合不确定性。
2. 全部 **251 个 >12 h** 的 Primary 半衰期估计保留，整体范围为 0.973843235–43.37544277 h。没有截断、删除、winsorize 或以这些估计另行选子集；长半衰期涉及超出采样时长的估计限制。
3. 5,000 次 gene bootstrap 的 CI 条件于固定目标和模型，未包含半衰期拟合、训练或患者间不确定性，也不将相关基因/实验重复视为独立患者。
4. 本轮没有将新标签用于拟合、校准、融合选择或模型选择。来源审计未发现已记录实验 accession 重叠，但并未进行 reads 级重复检查。
5. 结论只适用于该 MSK107Li shCtrl PDO 背景及可评估基因，不称为未见基因泛化、多患者临床验证或生物机制的因果证明。
